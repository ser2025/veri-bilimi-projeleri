# 🏗️ Beton Basınç Dayanımı Tahmini (Regresyon ve Sınıflandırma)

Beton karışımındaki malzemelerden basınç dayanımını tahmin eden iki problemli proje.

**Defter:** [`Beton_Dayanimi.ipynb`](Beton_Dayanimi.ipynb)

## Yöntem
9 klasik regresyon ve 8 sınıflandırma algoritması, Keras sinir ağları, XGBoost.

## Sonuç
Regresyon: XGBoost **R² 0,917** (ortalama 3 MPa hata). Sınıflandırma: Random Forest **%88,8** accuracy.

## Veri
`concrete.csv` (UCI Concrete Compressive Strength)
