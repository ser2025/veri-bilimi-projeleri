# 🚢 Titanic Hayatta Kalma Tahmini (Makine Öğrenmesi)

Kaggle Titanic yarışması verisiyle yolcuların hayatta kalma durumunu tahmin eden sınıflandırma projesi.

**Defter:** [`Titanic_Project.ipynb`](Titanic_Project.ipynb)

## Yöntem
EDA ve görselleştirme, eksik veri doldurma, yeni özellikler (aile büyüklüğü, yalnız seyahat), Logistic Regression, Random Forest, Gradient Boosting, GaussianNB, BernoulliNB karşılaştırması.

## Sonuç
En yüksek doğrulama doğruluğu **%83,8** (Random Forest). Test setindeki 418 yolcu için Kaggle'a tahmin gönderildi (`kaggle_sonuc.png`).

## Veri
`ttrain.csv`, `ttest.csv` (Kaggle Titanic)
