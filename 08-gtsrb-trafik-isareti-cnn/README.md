# 🚦 GTSRB Trafik İşareti Sınıflandırma (Capstone, CNN)

43 sınıflı Alman trafik işareti veri setiyle CNN sınıflandırma bitirme projesi.

**Defter:** [`GTSRB_Trafik_Isareti.ipynb`](GTSRB_Trafik_Isareti.ipynb)

## Yöntem
ROI kırpma, iz bazlı doğrulama ayrımı (veri sızıntısını önleme), yön işaretlerine uygun veri çoğaltma.

## Sonuç
Resmi test setinde accuracy **~%96,0**. Eğitilmiş model Hugging Face'te paylaşılmaktadır.

## Veri
GTSRB (Kaggle: German Traffic Sign Recognition Benchmark; `Train.csv`, `Test.csv`)
