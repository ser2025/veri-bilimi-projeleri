# 🧠 Titanic: Keras ile Derin Öğrenme

Titanic hayatta kalma tahmininin Keras sinir ağlarıyla çözümü.

**Defter:** [`Titanic_Keras.ipynb`](Titanic_Keras.ipynb)

## Yöntem
5 farklı Keras modeli, StandardScaler ve EarlyStopping etkisinin incelenmesi, Logistic Regression ile karşılaştırma.

## Sonuç
En iyi model (64-32-16, EarlyStopping) test accuracy **~%82,7**. Ölçeklendirme aynı modeli %77'den %82'ye çıkardı.
