# 🖼️ CIFAR-10 Görüntü Sınıflandırma (CNN)

10 sınıflı CIFAR-10 görüntülerini evrişimli sinir ağıyla sınıflandırma.

**Defter:** [`CIFAR10_CNN_Siniflandirma.ipynb`](CIFAR10_CNN_Siniflandirma.ipynb)

## Yöntem
Basit CNN ile derin CNN ve veri çoğaltmanın karşılaştırılması, karışıklık matrisi analizi.

## Sonuç
Derin CNN + veri çoğaltma test accuracy **~%80,7** (basit CNN ~%59,3).

## Veri
CIFAR-10 (Keras üzerinden otomatik indirilir)
